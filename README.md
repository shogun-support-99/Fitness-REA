# Forge Fitness

A polished, responsive workout-tracker landing page and interactive product demo inspired by the best patterns in modern fitness apps.

## Run locally

```bash
npm install
npm run dev
```

Open the URL printed by Vite. Build for production with `npm run build`.

## Included

- Responsive product landing page
- Interactive workout logger demo with sets, rest timer, and completion flow
- Mobile navigation and FAQ accordion
- Product, progress, community, and testimonial sections
- Accessible controls and reduced-motion support
